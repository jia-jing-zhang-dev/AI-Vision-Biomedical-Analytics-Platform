# AI Vision & Biomedical Analytics Platform

Interactive demo of a PyTorch / computer-vision project:

- **Biomedical segmentation**: classical methods, a U-Net trained on real BBBC039 nuclei, and the pretrained Cellpose model, scored with Dice, IoU and instance F1.
- **Blood-cell classification** (BloodMNIST, 8 classes): a custom CNN (96.7%) and a fine-tuned ResNet-18 (97.9%), with Grad-CAM heatmaps and calibrated confidences.
- **FashionMNIST** clothing classification.

Source code, training scripts, benchmarks and full results:
https://github.com/jia-jing-zhang-dev/AI-Vision-Biomedical-Analytics-Platform

This Space is a deployment snapshot generated by `deploy_hf.py` from that repository; make changes there.
Educational project, not a medical device. Data credits are listed in the GitHub README.
